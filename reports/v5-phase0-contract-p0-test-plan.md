## 3. P0 验收用例

| 编号 | P0 能力 | 验收口径 |
|---|---|---|
| AC-P0-01 | 自愈工作台 | 能按严重度查看诊断；单次执行动作有可见状态和结果；重复点击/刷新不触发重复副作用；已解决与过期项目可追溯但不干扰待办。 |
| AC-P0-02 | 桌面通知与开播预测 | 授权、拒绝、系统不支持三态都有明确反馈；同一直播事件不重复通知；预测仅按后端返回窗口展示，缺少可信数据时展示"暂无预测"。 |
| AC-P0-03 | 标签分组与搜索 | 标签可管理并在房间卡、筛选和搜索间一致；多标签组合不丢房间；全局搜索可定位房间、录制与告警，空结果/断网不白屏。 |
| AC-P0-04 | 监控总览与手动录制 | 开播角标、录制时长/进度与实际状态一致；手动开始的成功、未开播、已录制、失败均可理解且不重复建会话；详情抽屉不使用陈旧状态。 |
| AC-P0-05 | UI 视觉与深色模式 | 浅/深色状态色语义一致；文字与关键控件满足可读对比；加载、空、错误、弱网以及窄屏下无白屏、无遮挡、无不可达操作。 |
| AC-P0-06 | 桌面端双平台 | Tauri 桌面端能连接本机服务并处理目录/通知权限；macOS 与 Windows 安装包按同一状态机验证（BOOT-01~10）。 |
