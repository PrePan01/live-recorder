# Live Recorder V5 全量测试计划（Web 端 / 桌面客户端 / 后端 / 全平台）

> 维护人：@QA · 状态：待 PrePan 审阅

> 范围：V5 全部功能 + 此前版本（v1–v4）回归，覆盖 Web 端、桌面客户端（macOS/Windows）、后端，以及测试层级与门禁。

## 1. 目标与范围

- **目标**：交付一份按测试行业规范（分层测试、可追踪、可验收、有门禁）的 V5 全量测试计划，作为 V5 验收与回归的基线。
- **覆盖对象**：
  - 后端服务（HTTP API + SSE + WebSocket 预览 + 侧车进程）
  - Web 管理端（浏览器访问 localhost）
  - 桌面客户端（Tauri：macOS .app/.dmg + Windows .exe/.msi）
  - 平台适配器（抖音、B 站）
- **平台**：macOS、Windows（桌面双平台 + 浏览器）；V5 已移除移动端三平台（见 `v5-detailed-design.md` 历史决策），本计划不再含手机矩阵，仅保留浏览器响应式相关抽查。
- **批次**：P0-0（零命令启动/端口）→ P0（1–6）→ Batch2（7–10）→ Batch3（11–15）。

## 3. 测试环境与前提

### 3.1 测试替身契约（BE 必须可注入）

1. 平台状态/拉流适配器：可返回未开播、开播、受限、网络失败、断流、标题回退。
2. 录制器：可报告启动成功、写入失败、进度、结束、异常退出、0 字节。
3. 文件系统与磁盘：可模拟不可写、低空间、写入中断、目录越界。
4. SMTP/邮件发送器：记录调用、模拟超时/拒信/成功、预设回填。
5. OpenList/WebDAV 上传器：记录调用、模拟进度/失败/重试/取消/重复远端对象。
6. 时钟与调度器：可推进轮询、退避、去重窗口、定时计划（含跨天/时区），无真实等待。
7. 通知 API：可模拟权限被拒/已授权、投递成功/失败。
8. 原生能力（Tauri command）：`pickDirectory`、`openPath`、`notify`、服务健康，均可注入。

### 3.2 数据与安全前提

- 使用脱敏/可撤销的测试 Cookie；不得把凭据提交至仓库、日志、导出或告警。
- 所有敏感配置（Cookie、SMTP 密码、OpenList 令牌）读取接口只返回 `hasXxx`，不回显明文；导出/日志不得含密钥。
- 测试数据目录隔离；不污染用户真实录制目录与 live DB（回归用临时 worktree/副本库）。

## 9. 缺陷门禁与阻塞定义

### 9.1 阻塞缺陷（Blocker，任一出现即阻止发布）

1. 任一目标系统无法完成首次配置、保存或重启恢复。
2. 已启用且实际开播的有效房间无法启动录制，或同场直播产生并行/重复录制。
3. 文件未写入指定目录、历史记录与实际文件不一致、无法定位失败原因、录制时长显示错误。
4. 磁盘阈值未阻止新录制（可能耗尽磁盘）或断流重试无限循环。
5. 正在录制时关闭窗口丢录；明确退出未二次确认即停服务。
6. 敏感配置（Cookie/SMTP 密码/OpenList 令牌）在接口、日志、导出或告警中泄漏。
7. 关键依赖不可替换，导致异常场景无法在自动化中稳定复现。
8. 端口占用时无法自动恢复或误杀外部进程。
9. 桌面客户端白屏（WebView 渲染失败）或服务启动诊断缺失。

### 9.2 严重/次要分级

- **Critical**：核心功能异常但可绕过（如单类通知失效、单平台受限但可降级）。
- **Major**：非核心功能缺陷，有可接受 workaround。
- **Minor**：文案/样式/非阻塞体验问题。

## 10. 完成门槛（Definition of Done）

- **提测门槛**：L1–L3 用例可注入替身可用；接口契约已冻结；P0 验收项均有对应用例。
